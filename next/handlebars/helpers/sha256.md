Returns the SHA-256 digest of a string as hex. One-way and not safe for protecting secrets.

## Syntax

```sfmc
{{sha256 text [...options]}}
```

Returns `string`.

## Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `text` | string | Yes | The text to hash. |
| `options` | any | No, repeatable | Named argument charset: UTF-8 (default) or UTF-16. |

## Example

Tested in a Marketing Cloud Next email on 2026-11-22:

- `{{sha256 "abc"}}` renders `ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad`, as documented.
