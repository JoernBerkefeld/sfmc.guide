{% comment %} Renders the searchable / filterable / sortable AMPscript function catalog table. Shares its shape with ssjs.guide's function index (name, category, returns, description) and with differs-from-docs-list.html's control strip, so the two sites stay visually and behaviourally aligned instead of drifting apart. Usage: {% include ampscript-function-index.html entries=site.data.ampscript_functions empty="No functions catalogued yet." %} Parameters: entries (array) - a site.data.* list of function rows (may be empty/nil). empty (string) - sentence shown when there are no entries. mcn_only (bool) - keep only rows available on Marketing Cloud Next (non-empty `mcn`). Default: show everything. show_mcn (bool) - add the "API version" column and its sort mode. show_handlebars (bool) - add the "Handlebars" column (equivalent helper + the MCN caveat from `mcnNotes`). show_mapping (bool) - add the "Handlebars mapping" filter without the column (show_handlebars implies this too). Row fields come from scripts/generate-ampscript-function-index.mjs: name, slug, category, syntax, returnType, verified, url, differsFromDocs, deprecated, mcn, handlebarsEquivalent, mcnNotes, description, guideUrl A row is only linked when `verified` is true — an unverified row is catalogued, not proven, and must never link to a page that does not exist. Verification always happens on Engagement, so the link target stays under /engagement/ even when the table is rendered in the Next section. Hex literals mirror _sass/_variables.scss (SCSS vars are compile-time only). `description` MUST be escaped. Several catalog descriptions contain raw HTML tag names (BuildOptionList mentions
