`mcdev` (Accenture open source, maintained with community contributions) is the de-facto CI/CD toolchain for Engagement metadata: retrieve, deploy, clone, and document business-unit configuration from the command line.

Pair it with [SFMC DevTools for VS Code](/tools/vscode-sfmc-devtools/) for a graphical workflow and [eslint-plugin-mcdev](/tools/eslint-plugin-mcdev/) to surface `.mcdev-validations.js` rules in the editor and CI.
